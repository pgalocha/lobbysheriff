# Política de Segurança

## Reportar uma vulnerabilidade

**Não abras uma issue pública** para problemas de segurança.

Usa o reporte privado do GitHub: separador **Security → Report a vulnerability**
neste repositório. Inclui uma descrição do problema, os passos para o reproduzir
e o impacto esperado.

Vou confirmar a receção e dar seguimento logo que possível.

## Âmbito

- Serviços em `services/`, `frontend/` e `gateway/`
- Exposição de secrets (por exemplo, a `FACEIT_API_KEY`)
- Configuração de CI/CD em `.github/`
